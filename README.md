# 收神记｜公开站说明

这是老道覃宏个人探索档案与东方生命文化观察平台。公开内容围绕人物探索经历、注意力与生命状态、传统文化观察、探索影像和档案记录展开。

## 公开结构

- `index.html`：收神记公开首页
- `p/`：老道覃宏个人探索档案
- `p/observations/`：东方生命观察
- `p/films/`：探索影像
- `p/archive/`：探索档案
- `shoushenji/`、`wuji/`、`about/`、`insights/`：相关文化资料页

## 内容边界

站点只读取 `content-public/` 中已编辑、适合公开的资料。页面内容遵循文化资料、个人记录、现场记录与可验证资料的公开边界。

域名启用文件保存在 `deployment/CNAME.pending`；在 DNS、HTTPS 与正式上线条件确认前，请勿将其放入站点根目录。
