# 收神记品牌官网 V1.0

正式域名：`shoushenji.cn`。本项目是无构建依赖的静态网站，可先由 GitHub Pages 托管，后续可整体迁移至腾讯云静态托管 / COS；当前不包含会员、支付、商城、报名表单或后台。

## 页面

- `index.html`：品牌首页
- `about/`：老道文化（人物信任）
- `shoushenji/`：收神记（大众入口）
- `wuji/`：无极门（文化根基）
- `courses/`、`retreat/`：课程与体验承接页
- `insights/`：视频与文章入口

## 维护原则

所有页面共用 `style.css` 与 `script.js`；图片、视频和图标素材分别放入 `assets/images/`、`assets/videos/`、`assets/icons/`。V1.0 仅沿用现有人物照片，待真人素材完成筛选后再替换主视觉与内容封面。上线前请更新实际的联系方式、课程状态和活动信息。
